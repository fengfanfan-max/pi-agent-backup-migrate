Config & Settings

bash — one file, entire agent state
# on your current machine
$ bash pi-agent-backup.sh backup
✅ Backup saved: pi-agent-backup-20260807.tar.gz
# includes data + migration checklist + restore script

# on your new machine — the tarball is all you need
$ tar xzf pi-agent-backup-20260807.tar.gz
$ bash ~/pi-agent-backup.sh restore pi-agent-backup-20260807.tar.gz
